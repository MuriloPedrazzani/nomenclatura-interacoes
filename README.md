# Nomes e IA — site do TCC

Site de divulgação do TCC sobre nomenclatura e predição seletiva de interações medicamentosas. Apresenta os resultados do benchmark retrospectivo exploratório baseado na RENAME e no DDInter.

**Acessar o site:** https://murilopedrazzani.github.io/tcc-nomes-e-ia-site/

Este repositório contém exclusivamente a página pública e seus recursos. O código científico permanece em [tcc-nomenclatura-interacoes](https://github.com/MuriloPedrazzani/tcc-nomenclatura-interacoes), mantido separadamente.

## Arquivos

- `index.html`: conteúdo e ilustrações.
- `estilos.css`: apresentação responsiva.
- `app.js`: navegação e interações.
- `dados.js`: agregados apresentados no site.
- `icone.svg`: ícone do site.
- `.nojekyll`: publicação estática sem processamento Jekyll.

## Executar e publicar

Abra `index.html` mantendo os arquivos juntos. Não há instalação, backend, chamada de modelo ou serviço externo necessário para utilizar a página.

O GitHub Pages publica a raiz da branch `main`. Alterações neste repositório não modificam o repositório científico.

## Escopo

Página de divulgação acadêmica. Os resultados são retrospectivos e exploratórios; a página não avalia combinações inseridas pelo visitante e não fornece recomendações clínicas.
